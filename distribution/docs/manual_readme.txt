설치
1. 게임을 종료하고 기존 자동 패치가 있으면 해당 설치기로 원본 복구합니다.
2. Steam의 관리 → 로컬 파일 찾아보기로 SignI.exe가 있는 폴더를 엽니다.
3. 그 안의 game 폴더 전체를 게임 폴더 밖의 안전한 장소에 복사해 백업합니다.
   세이브(%APPDATA%\RenPy\sign1-full, game\saves, 별도 지정 폴더)도 백업하세요.
4. 패치 ZIP을 게임 폴더 밖에 압축 해제합니다.
5. '패치파일' 안의 모든 내용을 SignI.exe가 있는 위치에 붙여넣습니다.
   패치파일 안의 game 폴더가 게임의 game 폴더와 합쳐져야 합니다.
   같은 이름의 파일은 덮어쓰며, 패치파일 폴더 자체를 복사하지 않습니다.
6. Steam에서 실행합니다. 첫 실행에는 정품 원본으로 한국어 이미지·영상 리소스를
   복원하므로 시작이 잠시 늦어질 수 있습니다. 완료될 때까지 기다려 주세요.
   다음 실행부터는 복원된 리소스를 사용합니다. 별도 설치 EXE나 Python 설치는 필요 없습니다.
7. 첫 패치 실행에는 한국어가 자동 선택됩니다. 한국어는 일본어 슬롯을 사용하며
   이후 사용자가 바꾼 언어 설정은 유지합니다.

삭제 및 원본 복구
1. 게임을 종료합니다. 최신 세이브가 game\saves에 있다면 먼저 따로 복사합니다.
2. 패치가 적용된 game 폴더의 이름을 game_한국어패치_보관 등으로 바꿉니다.
3. 설치 전에 백업했던 원본 game 폴더를 같은 위치에 복사합니다.
   단순히 원본을 덮어쓰기만 하면 패치가 추가한 파일이 남으므로 폴더를 교체해야 합니다.
4. 따로 보관한 최신 세이브를 필요에 따라 되돌리고 Steam에서 실행합니다.
자동판의 원본 복구 버튼은 수동으로 복사한 설치를 제거하지 않습니다.
Steam 파일 무결성 검사만으로 추가된 패치 파일이 제거되지는 않습니다.
