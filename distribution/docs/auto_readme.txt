배포본
이 자동 설치판에는 설치 EXE, README.txt, 제3자_라이선스_고지.txt가 들어 있습니다.
패치 데이터는 EXE에 내장되어 있으며, 별도 Python 설치는 필요하지 않습니다.
구매한 게임에 포함된 실행 환경과 원본 파일을 사용합니다.

자동 설치
1. 게임을 종료하고 게임 폴더와 세이브를 별도로 백업합니다.
   기본 세이브 위치: %APPDATA%\RenPy\sign1-full
   game\saves 또는 직접 지정한 저장 폴더도 확인해 주세요.
2. ZIP 전체를 게임 폴더 밖의 새 폴더에 압축 해제합니다.
3. 'Sign Broken Kether 한국어 패치 v1.0.1.exe'를 실행합니다.
4. 자동으로 표시된 게임 경로를 확인합니다. 경로가 비어 있거나 다르면
   '찾아보기'로 SignI.exe가 있는 게임 폴더를 선택합니다.
5. '한국어 패치 설치'를 누르고 완료 메시지가 나올 때까지 기다립니다.
6. Steam에서 게임을 실행합니다. 첫 패치 실행에는 한국어가 자동 선택됩니다.
   이후 사용자가 고른 언어 설정은 유지합니다. 한국어는 일본어 슬롯을 사용합니다.

원본 복구 및 재설치
게임을 종료하고 같은 EXE에서 설치했던 게임 폴더를 선택한 뒤 '원본 복구'를 누릅니다.
설치 전 파일을 복원하고 패치가 추가한 파일을 제거합니다. 세이브는 변경하지 않습니다.
게임 폴더의 Sign_KO_Backup에는 원본 백업과 복구 이력이 남습니다.
원본 복구 후 같은 버전을 다시 설치하면, 이전 백업은 그대로 보존하고 새 백업을 만듭니다.
이전 복구 이력이 남아 있어도 백업 폴더를 지우거나 이름을 바꿀 필요가 없습니다.
패치가 설치된 상태에서는 백업을 삭제하거나 이름을 바꾸지 마세요.
이전 버전은 해당 버전의 복구 도구로 먼저 제거한 후 새 버전을 설치하세요.
Steam 파일 무결성 검사만으로 추가된 패치 파일까지 제거되지는 않습니다.
